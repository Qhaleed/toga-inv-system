## Start the Vite Frontend

```sh
cd frontendvite
npm install
npm run dev
```

- The app will be available at http://localhost:3000

## Start the Backend

```sh
cd backend
npm install
npm install dotenv
npm run devStart   # enables nodemon (hot reload)
# or
node server.js
```
